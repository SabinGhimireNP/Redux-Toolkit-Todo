# Redux Toolkit Todo

A simple Todo application built with React and Redux Toolkit.

## Features

- Add, delete, and toggle todos
- State management powered by Redux Toolkit
- Modern React functional components

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SabinGhimireNP/Redux-Toolkit-Todo.git
   cd Redux-Toolkit-Todo
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the application:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**  
   Visit `http://localhost:5173` (or the port shown in your terminal).

## Project Structure

- `src/`: React components and Redux store
- `src/features/todos/`: Todo slice and related logic

## Technologies Used

- React
- Redux Toolkit
